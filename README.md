# Radiology Department Website — Version 2

Responsive multi-page static website for the Department of Radiology, Inlaks and Budhrani Hospital, Pune.

## Included pages
- `index.html` — Homepage
- `about.html` — Department overview
- `faculty.html` — Faculty and team directory
- `services.html` — Clinical imaging services
- `academics.html` — Residency and education
- `research.html` — Research and publications
- `news.html` — News and events
- `contact.html` — Contact and location
- `assets/css/site.css` — Shared styles
- `assets/js/site.js` — Mobile navigation

## Update your existing GitHub Pages site
1. Download and extract this ZIP.
2. Open your existing `radiology-department-site` GitHub repository.
3. Upload **the contents** of the extracted `radiology_department_v2` folder into the repository root.
4. Keep `index.html` at the root and preserve the `assets` folder structure.
5. Commit the changes to the `main` branch.
6. Wait for GitHub Pages to deploy, then refresh your published website.

## Before public launch
- Obtain written approval from hospital administration and the Head of Department.
- Confirm institutional naming, logo, brand standards and photo permissions.
- Verify every modality, equipment specification, service, phone number and operating hour.
- Replace faculty placeholders only with approved names, designations, photographs and biographies.
- Verify training programme and accreditation claims against current official records.
- Add only verified publications, abstracts, projects and achievements.
- Never publish patient-identifiable images, scans, reports or health information.
- Add an approved privacy notice before introducing forms, analytics or data collection.

## Editing
Edit the relevant `.html` page in a text editor. Shared visual styles are in `assets/css/site.css`.
