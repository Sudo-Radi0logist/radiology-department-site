# Department of Radiology — Inlaks & Budhrani Hospital

Responsive multi-page website for the Department of Radiology.

## Pages
- Home
- About
- Clinical Services
- Academics
- Research
- Our People
- News
- Contact

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload the contents of the `radiology_department_v2` folder into the root of the existing GitHub repository.
3. Preserve the `assets` folder and its subfolders.
4. Commit the changes to the `main` branch.
5. Wait for GitHub Pages to deploy, then refresh the published website.

## Editing
Edit the relevant `.html` page in a text editor. Shared visual styles are in `assets/css/site.css`; mobile navigation is in `assets/js/site.js`.
